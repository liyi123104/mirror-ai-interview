# 面镜架构

## 一次面试请求怎么走完全程

```
                  ① 浏览器打开 /login，拿 token
┌─────────┐   ② 上传简历 PDF     ③ 开始面试
│  浏览器  │ ──────────────────────────────┐
└─────────┘                                ▼
     │                              ┌───────────┐
     │   HTTPS/HTTP                 │   Nginx   │  静态资源 + 反代 /api
     └─────────────────────────────▶│  :80      │
                                   └─────┬─────┘
                                         │ /api/**
                                         ▼
                              ┌──────────────────────┐
                              │   Spring Boot :8080  │
                              │  JWT 鉴权 / 状态机     │
                              │  题库 CRUD / 报告汇总  │
                              └───┬──────────┬───────┘
                                  │          │
                    JDBC          │          │ HTTP（内网，带 X-Internal-Token）
                                  ▼          ▼
                          ┌───────────┐  ┌──────────────────┐
                          │  MySQL 8  │  │ FastAPI :8000    │
                          │ 6 张表     │  │ PDF 解析/向量检索  │
                          └───────────┘  │ 出题/追问/评分/复盘 │
                                         └───┬──────────┬───┘
                                             │          │
                                     HTTPS   │          │ HTTP
                                             ▼          ▼
                                   ┌──────────────┐ ┌──────────────┐
                                   │ DeepSeek API │ │ Ollama bge-m3│
                                   │ 出题/评分     │ │ 向量化        │
                                   └──────────────┘ └──────────────┘
```

## 三个边界（面试常问）

| 边界 | 规定 | 为什么 |
|---|---|---|
| 前端 ↔ 后端 | 只走 `/api/**`，前端不知道 Python 的存在 | AI 服务不对外暴露，改模型不动前端 |
| Spring Boot ↔ FastAPI | 内部 HTTP + `X-Internal-Token`，AI 服务不连数据库 | AI 服务无状态，可以横向扩容；上下文由 Java 传 |
| FastAPI ↔ 模型 | 主用 DeepSeek，失败降级本地 Ollama | 断网/欠费时也能出题，只是慢 |

## 数据流与一致性

- `interview_session`：一场面试的状态（ONGOING / FINISHED、轮数、深度、最后一题）
- `turn`：一问一答，`seq` 奇数偏差靠 `role` 区分；题目在 `seq`，回答在 `seq+1`
- `turn.dimensions_json`：这道题四个维度的分数，报告页雷达图的数据来源
- `cost_log`：每次 AI 调用的 token 与花费，按 `scene`（question/score）区分
- `report`：报告落库，`session_id` 唯一，重复请求直接返回同一份（幂等）

## 降级链路

| 故障 | 表现 | 兜底 |
|---|---|---|
| Python 服务挂了 | 开始面试/答题 502→映射成 5030 | 提示"面试服务暂时不可用"，不丢已存的数据 |
| DeepSeek 超时/欠费 | 出题变慢 | `llm.chat` 自动切 Ollama qwen2.5:7b |
| bge-m3 没起 | 检索为空 | 出题不带题库参考，仍然能问 |
| 简历解析失败 | `needsReview=true` | 仍返回规则抽取的技能，面试继续 |
